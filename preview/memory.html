When Memory Hurts: Amplifying Mission-Channel Attacks in LLM-Driven UAV Agents

Ibrahim Odat, Hamza Tawayha, Anyi Liu (Oakland University)

An LLM-driven UAV agent plans from what it sees: perception detections, telemetry, tool returns, and its own short-term memory. We corrupt one of these once, in a form the agent accepts as valid, and measure what bounded memory does to the damage across 1,920 runs, 12 planners, and ten seeds. Memory turns out to be a channel-specific amplifier, so a defense has to match the pathway the corruption came through.

Results

  1. S1

    False perception

    2.83×

    The largest amplification. Failure rises from 19.2% to 54.2% once the agent remembers what it saw.

  2. S2

    Forged tool return

    0.92

    False-belief persistence after injection. Failure barely moves, so scoring outcomes alone misses the corruption.

  3. S3

    Fabricated safety constraint

    70.0%

    Mission failure with memory, the highest of the four pathways.

  4. S4

    Direct memory poisoning

    0

    Belief persistence once a write-time memory monitor is added. The same monitor does not stop S1.
