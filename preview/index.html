PhD Candidate · Computer Science and Informatics · Oakland University

Ibrahim Odat

AI Security Researcher · Autonomous Systems and Offensive Security

I study the security of LLM-driven autonomous systems: how agents that plan from shared memory, sensor feeds, and tool outputs can be manipulated, and how to defend them without retraining the model or modifying the autopilot. My work combines adversarial machine learning, multi-agent systems, and UAV security. I am advised by Dr. Anyi Liu, and I release each project as an open-source testbed.

Research

Selected projects

ACM ASIA CCS 2027

AeroMind: shared-memory poisoning in LLM-driven UAV fleets

One compromised sensor feed writes false records into a fleet's shared memory, and UAVs that never sensed the data act on them. Includes the AeroMind testbed and a retrieval-boundary defense.

Project pageCode
IEEE ICMLA 2026

When Memory Hurts: memory as an attack amplifier

Bounded short-term memory raises mission failure under attack from 31.5% to 53.3% across 1,920 runs and 12 planners. A write-time monitor stops direct memory poisoning but not live perception attacks.

Project pagePaper
Rated untrustworthy. Acted on anyway.Belief versus action
arXiv 2026

Beyond Belief: misinformation in tool-using LLMs

Models often make harmful tool calls after rating a notice as untrustworthy. Measured across five models, with forewarning and fine-tuning tested as mitigations.
