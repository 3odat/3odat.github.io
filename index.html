§ 2

Research

Language models now plan missions, call tools, and remember across sessions. Each of those abilities is also a way in. I work on three questions.

  1. Memory as a control plane

    Agents that plan from shared, persistent memory inherit whatever was written there. I study how a few poisoned records steer a UAV fleet, how the effect spreads from one agent to the rest, and which retrieval-time checks stop it.

    AeroMindWhen Memory Hurts

  2. Belief versus action in tool-using LLMs

    A model can rate a notice as untrustworthy and still act on it. With collaborators, I measure that gap across models and test forewarning and fine-tuning as mitigations, counting the cost to legitimate tasks.

    Beyond Belief

  3. LLM-enabled attacks on UAV links

    Net-GPT showed that fine-tuned language models can imitate the traffic between a drone and its ground station well enough to drive a man-in-the-middle attack.

    Net-GPTUAS dataset

AeroMind

Accepted · ACM AsiaCCS 2027

Poisoning the shared-memory control plane of an LLM-driven multi-UAV system

When an LLM-driven UAV fleet coordinates through shared memory, that memory is the control plane. An attacker who gets a few false records into it does not need to touch the autopilot, the flight interface, or the model weights, and UAVs that never sensed the data act on it.

The figures below walk through the open-source AeroMind artifact.

The defense sits at the retrieval boundary, between shared memory and the planner. It needs no change to the model or the autopilot.

§ 4

When Memory Hurts

Published · ICMLA 2026

Short-term memory turns one bad input into a failed mission

An LLM-driven UAV agent plans from what it sees: perception detections, telemetry, tool returns, and its own short-term memory. We corrupt one of these once, in a form the agent accepts as valid, and measure what bounded memory does to the damage. 1,920 runs, 12 planners, ten seeds.

  1. S1

    False perception

    2.83×

    The largest amplification. Failure rises from 19.2% to 54.2% once the agent remembers what it saw.

  2. S2

    Forged tool return

    0.92

    False-belief persistence after injection. Failure barely moves, so scoring outcomes alone misses the corruption.

  3. S3

    Fabricated safety constraint

    70.0%

    Mission failure with memory, the highest of the four pathways.

  4. S4

    Direct memory poisoning

    0

    Belief persistence once a write-time memory monitor is added. The same monitor does not stop S1.

Read the paper Bounded memory is a channel-specific amplifier, so a defense has to match the pathway the corruption came through.

    When Memory Hurts: Amplifying Mission-Channel Attacks in LLM-Driven UAV Agents

    I. Odat, H. Tawayha, A. Liu

    25th International Conference on Machine Learning and Applications (ICMLA 2026), pp. 693–700

    Bounded short-term mission memory amplifies one-shot corruptions of the evidence a UAV agent sees. Across 1,920 runs and 12 planners, it raises attack-side mission failure from 31.5% to 53.3%. A write-time memory monitor stops direct memory poisoning but not live perception corruption.
